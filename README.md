
# ЛАБОРАТОРНА 1 З ДИСЦИПЛІНИ БАЗИ ДАНИХ ТА ІНФОРМАЦІЙНІ СИСТЕМИ

# Варіант 8. Соціальна мережа

База даних соціальної мережі реалізована в PostgreSQL з використанням умовних операторів для безпечного створення:

- `SELECT 'CREATE DATABASE social_network;' WHERE NOT EXISTS (SELECT FROM pg_database WHERE datname = 'social_network')\gexec` - перевіряє наявність бази даних перед створенням
- `CREATE TABLE IF NOT EXISTS` - створює таблиці, лише якщо вони ще не існують

Це запобігає помилкам при повторному виконанні скрипта та гарантує коректність структури даних.

## Схема бази даних

### Таблиця користувачів users
- `id`: Первинний ключ
- `username`: Нік користувача
- `email`: Пошта користувача
- `password`: Пароль користувача(звісно не хешований[на жаль])

### Таблиця дописів posts
- `id`: Первинний ключ
- `title`: Заголовок допису
- `content`: Текст допису
- `user_id`: Зовнішній ключ, що посилається на користувача-власника допису

### Таблиця коментарів comments
- `id`: Первинний ключ
- `content`: Текст коментаря
- `author_id`: Зовнішній ключ, що посилається автора(власника) коментаря
- `post_id`: Зовнішній ключ, що посилається пост, під яким написано коментар
- `created_at`: Час коментування

База даних попередньо виконує вставку тестових даних, а саме:
- Трьох користувачів,
- Трьох дописів
- Трьох коментарів

## Виконані запити

- Створення таблиць із зовнішними ключами
- Вставка даних
- Вибірка даних з JOIN-ами
- Зміна(оновлення) даних записів
- Видалення записів
